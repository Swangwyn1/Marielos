# Portafolio Fotográfico Inmersivo

Una galería web interactiva y espacial diseñada para mostrar proyectos fotográficos a través de una experiencia de usuario (UX) fluida y altamente visual. 

La interfaz elimina las distracciones tradicionales, utilizando un entorno 3D para la navegación y microinteracciones cuidadosas que mantienen el enfoque absoluto en la fotografía.

## Características Principales

- **Navegación Espacial 3D:** Implementación de un carrusel cilíndrico interactivo que permite al usuario explorar los proyectos mediante *scroll* o arrastre, con cálculos dinámicos de punto focal para asegurar el encuadre perfecto de cada imagen.
- **Visor Inmersivo (Lightbox):** Transición suave a un modo de pantalla completa que oscurece la interfaz (`backdrop-blur`) para apreciar la fotografía en alta resolución sin saltos de contexto.
- **Microinteracciones Limpias:** Elementos de la interfaz (como botones y enlaces sociales) que aparecen o se desvanecen dinámicamente según el estado del proyecto activo, evitando la sobrecarga cognitiva.
- **Diseño Responsivo:** Arquitectura adaptativa que transforma la disposición espacial y reubica los controles para garantizar una experiencia táctil intuitiva en dispositivos móviles.
- **Optimización y Métricas:** Integración nativa con **Vercel Analytics** y **Speed Insights** para el monitoreo del rendimiento y tráfico real, respetando la privacidad del usuario sin banners intrusivos.

## Stack Tecnológico

- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Animaciones:** [GSAP](https://gsap.com/) (GreenSock Animation Platform)
- **Despliegue y Analíticas:** [Vercel](https://vercel.com/)
